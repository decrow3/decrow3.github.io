# decrow3.github.io

Personal academic website built with Sphinx.

## Local build

```powershell
python -m pip install -r docs/requirements.txt
python -m sphinx -b html docs/source docs/build/html
```

To preview, serve the output folder (`_build/` is git-ignored):

```powershell
python -m sphinx -W -b html docs/source _build
python -m http.server 8765 --directory _build
```

## Site visuals

All current visuals are original illustrative schematics drawn as inline SVG. None shows measured data, model output, or material from a paper or grant, and each figure is labeled "Illustrative schematic" on the page.

| Visual | Source file | Basis |
| --- | --- | --- |
| Homepage hero (image, V1, V2 layers) | `docs/source/_includes/figures/hero_v1v2.html`, generated by `python docs/tools/make_hero_figure.py` | Drawn circle; "V1" is its tangent orientation, "V2" a local average. Textbook concepts only. |
| Contribution icons | `glyph_maps.html`, `glyph_active.html`, `glyph_running.html` | Decorative icons. |
| "Same response, different circuits" | `fig_circuits.html` | Generic circuit motifs illustrating the text on the Research page. |
| Measure / Model / Perturb | `fig_approach.html` | Restates the approach already described in the page text. |
| Training path | `about_path.html` | Restates the About text. |

Fonts (Inter, Newsreader) load from Google Fonts via `html_css_files` in `conf.py`; remove that entry to fall back to system fonts.

## Public content boundary

Research-direction copy must be supported by the public award summary or another identified public source. Reading a private grant document does not authorize publishing its contents. Keep proposal-only hypotheses, experimental specifics, preliminary figures, and unpublished results out of site source, comments, assets, and generated output unless explicitly cleared for publication.

Public award source: https://taggs.hhs.gov/Detail/AwardDetail?arg_AwardNum=K99EY037839&arg_ProgOfficeCode=124

For each new research visual, record the public paper/version, figure or dataset identifier, license, and modifications. Label measured data, model output, and illustrative schematics distinctly. Re-analysis of public data that produces a new scientific claim needs author review before publication. A public abstract or repository metadata entry does not establish that the full thesis or underlying raw data is public.

Current confirmed visual candidates:
- DM retinotopy paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC7608794/ (CC BY-NC 4.0; supplementary movies S1/S2; public model repository linked in paper; check repository license separately).
- Running paper: https://elifesciences.org/articles/87736 (CC BY; public processed data linked at https://doi.org/10.6084/m9.figshare.26508136.v1; raw data described as available on request).

Thesis full-text availability and the exact licenses/data releases for newer preprints still need verification before asset reuse.
